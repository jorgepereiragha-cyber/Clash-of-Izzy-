# Aplicação do relatório de licenciamento
Arquitetura existente: JavaScript ESM, assets/3d/manifest.json, engine/asset-loader.js, scripts/kingdom-3d.js, portal-worker.js e Node test. Não criar diretórios TypeScript/Astro fictícios.
Registro canônico assets/3d/licenses.json contém 8 GLBs e 2 texturas Kenney/Quaternius, SHA-256 e autoria. Data reviewedAt indica revisão, não data histórica de download. Licença CC0 ou CC-BY-4.0, créditos e alterações obrigatoriamente registrados. A verificação local não garante autoria legal; preservar evidência original. Mixamo e CC-BY-SA não aprovados para arquivos públicos neste momento; sem risco zero. Kenney continua fallback/protótipo. Não há modelos CC-BY incorporados hoje.
Comandos: npm run assets:licenses; npm run assets:validate; npm test; npm run build (dry run, sem publicação); node scripts/generate-licenses.mjs --write para regenerar créditos após revisão explícita. CI exige hash e créditos sincronizados. Não importar arquivos indiscriminadamente. Próximas fases: PBR licenciadas, 5 castelos, 16 edifícios, 9 variações de dragão, tropas, asas, skins, animações e áudio. A contagem do relatório não é consistente com a soma de categorias (5+16+9+11=41 antes de asas e skins); mapear por chaves reais do jogo. Não declarar todos os assets adquiridos até comprovação.
