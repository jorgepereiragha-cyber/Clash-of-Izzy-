# Resource HUD artwork

Five 128px PNGs were inspected visually and copied unchanged from https://github.com/Vitexus/ishtaria-client/tree/1cc1017b21c3045867bcf44928789205445bfe1f . The project's README identifies the following CC0 model sources and its icon bake tool documents the mappings. The icon files are rendered derivatives; attribution is preserved voluntarily. No game code was copied.

- food.png: assets/kenney/food-kit/corn.png — Kenney Food Kit https://kenney.nl/assets/food-kit
- wood.png: assets/icons/items/oak_log.png — Kenney Survival Kit https://kenney.nl/assets/survival-kit
- stone.png: assets/icons/items/stone.png — Kenney Survival Kit (resource-stone, gray tint)
- iron.png: assets/icons/items/iron_ingot.png — Quaternius Ultimate RPG Items gold_ingots model, tinted iron by the source bake tool
- gold.png: assets/icons/items/gold_ingots.png — Quaternius Ultimate RPG Items https://poly.pizza/bundle/Ultimate-RPG-Items-Bundle-h8mhlZ0dG8
- diamond.svg: original simple faceted diamond illustration authored for Clash of Izzy; not an external asset.

CC0: https://creativecommons.org/publicdomain/zero/1.0/
Source mapping: tools/bake-item-icons.gd, README.md and pack license files in the pinned repository. No pricing, economy, state or database changes. Original glyphs remain visible until successful image load.
